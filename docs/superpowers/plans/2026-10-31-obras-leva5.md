## Review Focus
1. Código errado 5 vezes invalida o código; 6º pedido na hora recusado com a mesma mensagem genérica. Teste na Task 2.
2. Acesso desativado derruba a sessão no próximo request. Teste na Task 2.
3. Obra de outro cliente pela URL → 404, sem vazar nome. Teste na Task 4.
4. Documento de outra obra pelo id → 404; URL assinada curta (≤ 5 min). Teste na Task 5.
5. Mensagem do cliente com HTML/script aparece como texto no hub e no e-mail ao engenheiro. Teste na Task 5.
