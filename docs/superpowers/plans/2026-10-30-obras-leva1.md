### Task 2: Motor — início fixo, dias restantes, etapas, Δ vs base

**Files:** Modify `app/obras/obras/_lib/cronograma.ts`; Test `app/obras/obras/_lib/__tests__/cronograma-leva1.test.ts`.

**Interfaces — Produces (exportados de `cronograma.ts`):**
- `AtividadePlano` ganha `inicioFixo: string | null`; `AtividadeExec` ganha `diasRestantes: number | null`.
- `AtividadeCalculada` ganha `alertaInicioFixo: string | null` (ex.: `'Começa antes da atividade 5 terminar'`), `inicioFixoAjustado: boolean` (caiu em folga e foi para o próximo útil).
- `calcularCronograma` passa a aceitar `dataStatus?: string` (padrão `hoje`).
- `type ResumoEtapa = { etapa: string; inicio: string; fim: string; diasUteis: number; percentual: number; inicioProjetado: string; fimProjetado: string; numeros: number[] }`
- `function resumirEtapas(atividades: AtividadeCalculada[], feriados: Feriados): ResumoEtapa[]` — na ordem de aparição; % ponderado por `peso`, ou por `duracao` quando a soma dos pesos da etapa é 0.
- `type ComparacaoBase = { numero: number; inicioBase: string | null; fimBase: string | null; deltaDias: number | null }`
- `function compararComBase(vigente: AtividadeCalculada[], base: AtividadeCalculada[] | null, feriados: Feriados): Map<number, ComparacaoBase>` — `deltaDias` = dias úteis entre `fimBase` e `fimProjetado` (positivo = atraso; `diasUteisEntre(fimBase,fimProjetado)-1` quando depois, negativo simétrico quando antes, 0 igual); `null` se a atividade não existe na base.
- `function duracaoPorFim(inicio: string, fim: string, feriados: Feriados): number` — dias úteis inclusivos; lança `Error('Fim antes do início (dd/mm)')` se `fim < inicio`.
- Regras (spec §5 e §8.1-3): **planejado** com `inicioFixo` = `proximoDiaUtil(inicioFixo)`, ignorando predecessoras (alerta se < fim previsto de alguma predecessora + 1); **projeção** em andamento/concluída usa início real; não iniciada usa `max(proximoDiaUtil(inicioFixo), fimProjetado preds + 1, proximoDiaUtil(dataStatus) se já passou)`; **dias restantes** informados em atividade em andamento → `fimProjetado = diasRestantes === 0 ? dataStatus : somarDiasUteis(proximoDiaUtil(dataStatus), diasRestantes - 1)`.

  - atividade 7 com `inicioFixo = '2026-11-03'` e predecessora 6 terminando `'2026-11-04'` → `alertaInicioFixo` contém `'atividade 6'`; sucessora 9 parte do fim da 7.

  - `compararComBase` com vigente igual à base → todos `deltaDias === 0`; atividade nova na vigente → `null`.
  - `duracaoPorFim('2026-10-29','2026-11-03', F) === 3`; fim antes do início lança.
  - Testes antigos de `cronograma.test.ts` continuam verdes (atividades sem `inicioFixo`/`diasRestantes` = comportamento anterior).

**Files:** Create `app/obras/obras/_lib/curvas.ts`; Test `__tests__/curvas.test.ts`; Modify `leitura.ts` (ler `obras_atividade_status_hist`).

- `function progressoPorPeriodo(base: Serie, previsto: Serie, realizado: Serie): { periodo: string; base: number; previsto: number; realizado: number }[]` — diferença entre pontos consecutivos (p.p.).
- `ObraGrande` ganha `hist: PontoHist[]` e `dadosAte: string | null` (maior `dataStatus` do histórico ou último `validado_em` de RDO).
