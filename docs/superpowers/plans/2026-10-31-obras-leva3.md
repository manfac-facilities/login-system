### Task 1: SQL
- `obras_restricao` (id, obra_id fk, atividade_numero int not null, tipo check `acesso|material|mao_de_obra|projeto|decisao_cliente|equipamento|outro`, descricao text not null, responsavel check `cliente|manfac|terceiro`, prazo date null, situacao check `identificada|em_tratativa|liberada` default identificada, liberada_em timestamptz, criado_por/criado_em (forçados), atualizado_por/atualizado_em (forçados no UPDATE)). RLS select/insert/update `obras_has_access()`; delete autor ou admin (trigger ou policy); liberada_em preenchido pelo trigger ao entrar em liberada e limpo ao sair.
- `obras_plano_semana` (id, obra_id, semana_inicio date check isodow=1, fechado_em, fechado_por (forçados), unique(obra_id, semana_inicio)) + `obras_plano_item` (id, plano_id fk cascade, numero int, meta_percentual numeric check 0..1, percentual_final numeric null, cumprido bool null, causa text null check em CausaRdo, avaliado_em/avaliado_por (forçados), unique(plano_id, numero)). ### Task 2: Motor Last Planner (`_lib/last-planner.ts`, puro, sem banco)
**Interfaces (produz):**
- `segundaDaSemana(dataIso): string`; `diasDaSemana(segundaIso): string[]` (seg–sex).
- `dataEnvioSemanal(segundaIso, feriados: Set<string>): string` — sexta, ou o último dia útil anterior da mesma semana.
- `lookahead(atividades: AtividadeCalculada[], restricoes: Restricao[], hojeIso, semanas: 3|4|6): SemanaLookahead[]` — `{ segunda, itens: { numero, codigo, nome, inicio, termino, restricoesAbertas: Restricao[], pronta: boolean }[] }`; inclui não concluídas cujo início (projetado, senão previsto) cai na janela; ordena por início.
- `avaliarItem(meta, percentualFinal): boolean` (≥ com tolerância 0,0001).
- `ppc(itens: {cumprido: boolean|null}[]): number | null` (null se nenhum avaliado).
- `causasNaoCumpridas(itens) : {causa, responsavel, n}[]` usando o mapa de `email-diario.ts`.
- Tipos `Restricao`, `PlanoSemana`, `PlanoItem` em `_lib/last-planner.ts`; leitores `lerRestricoes`, `lerPlano(obra, segunda)`, `lerPlanos(obra)` em `_lib/leitura.ts`.
- [ ] TDD: semana com feriado na sexta; lookahead respeita janela e restrição liberada não conta; PPC vazio null; commit.
